🚀 NOTIFICATION ORCHESTRATOR - QUICK START GUIDE
================================================

📍 ACCESS THE APPLICATION
-------------------------
1. Open browser: http://localhost:3000/login.html
2. Register a new account or login

👥 VIEW ALL USERS
-----------------
1. Click "Users" tab in sidebar
2. Click "Refresh" to load all users
3. Use search bar to find specific users
4. Click "Send Notification" on any user

📧 SEND A NOTIFICATION
----------------------
1. Click "Send Notification" tab
2. Enter username or user ID
3. Select event type (User Signup, Order, etc.)
4. Select priority (Low, Normal, High, Urgent)
5. Click channels to select (Email, SMS, Push, In-App)
6. Use JSON templates or write custom metadata
7. Click "Send Notification"

📝 USE JSON TEMPLATES
---------------------
Quick templates available:
- 👤 User Info: Basic user information
- 📦 Order: Order confirmation details
- 🔑 Password Reset: Password reset info
- 🔒 Security Alert: Security notifications
- 📣 Marketing: Marketing campaigns
- ⭕ Empty: Start from scratch

How to use:
1. Click any template button
2. Template loads into metadata field
3. Modify values as needed
4. Send notification

✅ CHANNEL SELECTION
--------------------
- Click on channel chips to toggle
- Selected channels show blue border
- Click "Select All" to select all
- At least one channel required

🔍 CHECK NOTIFICATION STATUS
----------------------------
1. Click "Check Status" tab
2. Enter Event ID or Notification ID
3. Click "Track"
4. View delivery status per channel

⚙️ MANAGE USER PREFERENCES
---------------------------
1. Click "User Preferences" tab
2. Enter User ID
3. Click "Load Preferences"
4. Update settings
5. Click "Save Preferences"

📋 CREATE TEMPLATES
-------------------
1. Click "Templates" tab
2. Click "New Template"
3. Fill in template details
4. Use {{variable}} for dynamic content
5. Click "Save Template"

🎯 TIPS & TRICKS
----------------
✅ Use username instead of user_id for easier sending
✅ JSON templates save time - click and modify
✅ Format JSON button cleans up your metadata
✅ Schedule time is optional - leave empty for immediate send
✅ Check dashboard for statistics and recent activity
✅ Use search in Users tab to find users quickly

🐛 TROUBLESHOOTING
------------------
❌ "Select at least one channel" error
   → Click on channel chips to select them
   → Make sure at least one is highlighted

❌ "Invalid JSON" error
   → Use JSON templates as starting point
   → Click "Format JSON" to validate
   → Check for missing commas or quotes

❌ "User not found" error
   → Check username spelling
   → Go to Users tab to see available users
   → Use exact username from Users list

📊 DASHBOARD
------------
- View total notifications sent
- See delivered, pending, and failed counts
- Charts show distribution by event type and channel
- Recent activity shows latest notifications

🔐 SECURITY
-----------
- All endpoints require authentication
- JWT tokens expire after 24 hours
- Passwords are hashed with bcrypt
- Protected routes redirect to login

💡 BEST PRACTICES
-----------------
1. Always test with one user first
2. Use appropriate priority levels
3. Select relevant channels for event type
4. Include meaningful metadata
5. Check status after sending
6. Review dashboard regularly

📞 SUPPORT
----------
For issues or questions:
- Check browser console (F12) for errors
- Check server logs for backend errors
- Verify MongoDB and Redis connections
- Review TEST_RESULTS.txt for system status

🎉 ENJOY USING NOTIFICATION ORCHESTRATOR!
