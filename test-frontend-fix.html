Testing In-App Notifications Fix

Steps to Test:

  1. Open the app at http://localhost:3000
  2. Open browser console (F12)
  3. Check what's in localStorage: 
    console.log('Auth user:', JSON.parse(localStorage.getItem('user')))
  4. The user object should have an 'id' field
  5. Click the bell icon to open notifications
  6. Check console logs for: 
    [InApp] Loading notifications for user: 69f9f5f9c0e3c31d321fc990
  7. You should see 4 unread notifications!

If Still Not Working:

Run this in browser console to check the API directly:

fetch('http://localhost:3000/api/inapp/notifications?user_id=69f9f5f9c0e3c31d321fc990', {
    headers: {
        'Authorization': 'Bearer ' + localStorage.getItem('token')
    }
})
.then(r => r.json())
.then(d => console.log('API Response:', d))
